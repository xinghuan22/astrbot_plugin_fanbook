# helloworld

AstrBot 插件模板

A template plugin for AstrBot plugin feature

IQDB 搜图结果中的 Danbooru、Gelbooru、yande.re 和 Konachan 链接会转换为
image-gateway 查看页面：

```text
https://image.lospro.kissnab.top/view?url=<URL 编码后的原站作品地址>
```

可以在插件配置的“图片结果页面地址”中修改域名。其他 IQDB 图源继续返回原始链接。
